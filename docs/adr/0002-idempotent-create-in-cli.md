# 冪等な Issue 作成を CLI に吸収する

Asana 連携時の重複 Issue 防止メカニズム（マーカー走査 → 既存なら再利用 / 無ければ作成 → 不確実なら再走査）を CLI 側の `issue create --dedupe-key` として実装し、スキル側の Bash ガードに依存しない。本文は呼び出し側が埋め込み、CLI は注入しない。作成前に本文中に構造化マーカー（ラベル＋値）がちょうど 1 回存在することを検証し、欠落なら検証不一致で失敗する。応答喪失時は同一プロセス内で即再走査し、1 件なら再利用として報告、0 件なら不確実記録を残して不確実終了とする。不確実記録がある限り再作成しない（明示オーバーライドのみ許可）。終了コード契約: 0=成功（再利用含む）/ 2=不確実・再実行で走査整合 / 3=曖昧・人手確認 / 4=認証失敗 / 5=検証不一致。
